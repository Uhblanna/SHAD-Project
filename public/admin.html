ADMIN TOOLS

Admin Panel

Clear system issue tickets, upload staff contacts, and upload the staff schedule.

Issue Tickets

Clear all submitted System Issues tickets.

Upload Committee Options CSV

CSV columns required: Name, Type, Description

Example: Basketball,Sports,Pickup games every weekend morning

Type must be either Sports or Project.

Upload Schedule CSV

CSV columns required: Name, Role, Status, Hours

Example: Sarah Kim,PA,duty,8AM - 4PM

Upload Staff CSV

CSV columns required: Name, Email, Slack

Example: Sarah Kim,sarah@email.com,https://slack.com/...

Upload Student CSV

CSV columns accepted: Name, Pronouns, Group, Age, Instrument, Medication, Dietary, Note

Example: Jane Smith,she/her,Group 1,16,Violin,None,Vegetarian,Quiet student
