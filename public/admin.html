Upload Schedule CSV

Upload the PA weekly schedule CSV exported from Excel. The file should include rows like Sunday 2026-07-05, followed by Time Block, Activity, PA1, PA2...

Example format: Week 1 Schedule, then Sunday 2026-07-05, then Time Block, Activity, PA1, PA2...

Upload Staff CSV

CSV columns required: Name, Email, Slack

Example: Sarah Kim,sarah@email.com,https://slack.com/...

Upload Student CSV

CSV columns accepted: Name, Pronouns, Group, Age, Instrument, Medication, Dietary, Note

Example: Jane Smith,she/her,Group 1,16,Violin,None,Vegetarian,Quiet student

Upload Med Kits CSV

CSV columns required: QRCode, Name, AssignedStaff, Location, Status, Supplies

Example: MEDKIT-001,Main Med Kit,Sarah Kim,Lecture Hall,Ready,Fully stocked
