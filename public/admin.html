Upload Schedule CSV

Upload the PA weekly schedule CSV exported from Excel. The file should include rows like Sunday 2026-07-05, followed by Time Block, Activity, PA1, PA2...

Example format: Week 1 Schedule, then Sunday 2026-07-05, then Time Block, Activity, PA1, PA2...

SHAD 2026 Program Schedule

Upload one CSV per week. The file should use the timetable grid format: first row is day names, first column is the time, cells contain activity names. Each upload replaces any existing data for that week label.

CSV format: first row = day names (Sunday…Saturday), first column = time (6:00, 7:00…), cells = activity text.

Upload Student CSV

Upload the SHAD application export CSV directly — all fields are captured automatically. Required columns: FirstName, LastName. All other columns below are stored if present.

Recognized columns:

Campus · AppID · LastName · FirstName · PrefName · Gender · Self-ID Gender · Pronoun · Self-ID Pronoun · DOB · Age Start Prog · Notes for PD to be aware of · City · Prov · Email · Phone · School · Grade · Ethnicity · Self-Desc Ethnicity · Indig? · Self-Des Indig. · Language Pref · Parent First Name · Parent Last Name · Relationship To Applicant · Parent Email Address · Parent Phone # · 2SLGBTQ+ · City Size · Region · Hoodie Size · Dietary Restrictions And/Or Intolerances · Allergies · Epipen?

Upload Room Numbers CSV

CSV columns required: FirstName, LastName, RoomNumber. Students are matched by first + last name.
